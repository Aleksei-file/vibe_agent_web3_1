# 🚀 Запуск проекта DeFi Insight Dashboard

## Шаг 1: Установка зависимостей
```bash
npm install
```

## Шаг 2: Запуск в режиме разработки
```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`

## Полезные команды

| Команда | Описание |
|---------|---------|
| `npm run dev` | Запуск dev сервера |
| `npm run build` | Production сборка |
| `npm run preview` | Preview production сборки |
| `npm run lint` | Проверка кода (ESLint) |
| `npm run format` | Форматирование кода (Prettier) |
| `npm run typecheck` | Проверка типов TypeScript |

## 📱 Функции приложения

1. **Connect Wallet** — подключение кошелька
2. **Account Overview** — информация об аккаунте
3. **Yield Farming** — стейкинг токенов
4. **Transaction Feed** — история транзакций

Все данные используют mock данные для демонстрации.
